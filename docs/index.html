Tic Tac Math

A playful math game where you race against a classic Microsoft Agent to solve Tic Tac Toe with math!

How to Play:

  • Tap any empty cell to answer the math equation
  • Get three in a row (horizontal, vertical, or diagonal) to win
  • The agent will take its turn if you don't win first

Controls:

  • Use the numeric keypad to enter answers
  • Customize game settings in the control deck
